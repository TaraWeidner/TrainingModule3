# Inclusive Health Training Module 3

Interactive employee training for **Module 3: Operations, Workflow & Quality Optimization**.

## Courses

- 3.1 Reception & Patient Access Workflow Optimization
- 3.2 Clinical Workflow Optimization & Throughput
- 3.3 Documentation Standards, Templates & Coding Accuracy
- 3.4 Inbox Management, Messaging & Workload Control
- 3.5 Patient Flow, Space Utilization & Clinic Layout
- 3.6 Supply Chain, Inventory Control & Procurement
- 3.7 Clinical Technology, Equipment & EHR Optimization
- 3.8 Quality Assurance, Continuous Improvement & Audits

## Learner experience

Each course includes:
- interactive curriculum lessons
- role-specific application
- source-derived competency checklist
- 20-question scored assessment
- 80% passing requirement
- attempt / best-score tracking
- employee attestation
- printable completion certificate
- CSV record export

Progress is stored in the browser using `localStorage`.
